# Export guide (fast)

## Minimum exports (to generate code structure)
- 1) Home/landing frame (desktop)
- 2) Same frame (mobile)
- 3) Components page screenshot: buttons + inputs + cards

## Recommended exports (more accurate)
- Export section frames (Hero, Features, Pricing, Footer) individually
- Export icons as SVG
- Provide typography styles list and color styles list

## If you use Figma tokens plugin
Export token JSON and place it under `src/design_system/tokens/`.
